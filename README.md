## Features

- **Hero Image Slider** — Auto-rotating background with dot navigation
- **Dark / Light Theme Toggle** — Persistent preference via localStorage
- **Scroll Animations** — Reveal-on-scroll effects across all sections
- **FAQ Accordion** — "Coming together" slide-in animation on scroll
- **Autoplay Video Section** — Background video with overlay content
- **Anti-Clone Protection** — Right-click, text selection, DevTools detection, keyboard shortcuts blocked
- **WhatsApp Integration** — All CTAs and contact form forward to WhatsApp
- **Fully Responsive** — Mobile-first design with hamburger menu
